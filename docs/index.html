轻量级、存储无关的 Go HTTP 会话管理库。 A lightweight, storage-agnostic HTTP session library for Go.

特性Features

可插拔存储Pluggable storage

内存、Redis、SQL（SQLite / PostgreSQL）三种实现，统一遵循 SessionStore 接口。In-memory, Redis, and SQL (SQLite / PostgreSQL) backends behind one SessionStore interface.

HTTP 集成HTTP integration

SessionManager 基于 net/http 提供 Cookie 会话与后台 GC。SessionManager provides cookie sessions and a background GC over net/http.

统一过期语义Consistent expiry

TTL 惰性校验 + 后台回收；Count 全后端返回活动会话数。Lazy TTL validation plus background GC; Count returns active sessions everywhere.

并发安全Concurrency-safe

各后端对读写加锁或使用单连接客户端，可安全用于并发 handler。Each backend guards its paths or uses a single client — safe under concurrent handlers.

快速开始Quick start

内存存储（memory）In-memory store (memory)

package main

import (
    "net/http"

    "github.com/shanjunmei/go-session"
    "github.com/shanjunmei/go-session/memory"
)

func handler(w http.ResponseWriter, r *http.Request) {
    store := memory.NewStore()
    m := session.NewManager(store)
    _ = m.Start()
    defer m.Stop()

    // create=true: auto-create when missing
    sess, err := m.GetSession(w, r, true)
    if err != nil {
        http.Error(w, err.Error(), http.StatusInternalServerError)
        return
    }
    sess.Set("user", 42)
}

SQL 存储（sqlstore）SQL store (sqlstore)

import (
    "database/sql"

    _ "modernc.org/sqlite" // pure-Go SQLite driver

    "github.com/shanjunmei/go-session"
    "github.com/shanjunmei/go-session/sqlstore"
    "github.com/shanjunmei/go-session/sqlstore/sqlite"
)

db, err := sql.Open("sqlite", "sessions.db")
if err != nil {
    panic(err)
}
// use postgres.Dialect for PostgreSQL
store, err := sqlstore.NewStore(db, sqlite.Dialect)
if err != nil {
    panic(err)
}
m := session.NewManager(store)

NewStore 构造时执行一次 CREATE TABLE IF NOT EXISTS sessions（字段：id、data、expires_at、last_accessed）。NewStore runs CREATE TABLE IF NOT EXISTS sessions once (columns: id, data, expires_at, last_accessed).

配置项（Option）Configuration (Option)

m := session.NewManager(store,
    session.WithName("sid"),
    session.WithPath("/"),
    session.WithDomain("example.com"),
    session.WithSecure(true),

关于 CountOn Count

契约：Count 返回当前活动（未过期）会话数，用于监控/指标。三个后端保持一致：Contract: Count returns the number of active (non-expired) sessions, for monitoring/metrics. All three backends stay consistent:

  • memory：排除 IsExpired() 为真的会话。memory: excludes sessions where IsExpired() is true.
  • sqlstore：SELECT COUNT(*) FROM sessions WHERE expires_at > ?。sqlstore: SELECT COUNT(*) FROM sessions WHERE expires_at > ?.
  • redis：SCAN session:* 分批迭代，对每个 key 批量查询 PTTL，仅计入 TTL 仍有效（或持久无过期）的 key，从而排除 TTL 已到期、但 Redis 后台尚未淘汰的物理 key。redis: iterates session:* with SCAN in batches, queries PTTL per key in a pipeline, and counts only keys whose TTL is still valid (or persistent) — excluding keys whose TTL elapsed but Redis has not yet evicted.
